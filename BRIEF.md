# My Links - Project Brief
A persona link-in-bio page. One page, clean design, mobile first
I want to send people here from my social profiles. 

## Tech
- Pure HTML, CSS, and JavaScript - no framework, no build tools
- Single index.html file (CSS and JS can be separate files)
- Deployes to Vercel as a static site

## Design
- Centered card layout, max-width 480pc
- My name as a heading, short build underneath
- Profile photo placeholder (circle, 120px)
- Light mode by defaul with a light/dark toggle
- Search hover animation on the link buttons
- Google font: Inter
- Use blue and orange gradients, in light mode and purple and blue in dark

## Links
Displays these as stacked buttons, full-width within the card:
